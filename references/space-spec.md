# スペース仕様（作成時にこのまま使う）

スペース名：PLaMo翻訳（fullstack、サイドバーに配置）

- 翻訳エンジンは外部APIやクラウドLLMを使わない。このMuse VM内で常駐起動済みのローカルモデルサーバーを使うこと。エンドポイントは http://127.0.0.1:18080/v1/chat/completions （llama.cpp llama-server、OpenAI互換、モデルは pfnet/plamo-3-translate-0.8b GGUF Q4_K_M）。リクエスト形式は {"messages":[{"role":"user","content":"<原文>"}], "temperature":0, "max_tokens":1024} で、応答の choices[0].message.content が訳文。サーバーの /health が {"status":"ok"} を返す。
- モデル側の chat template が言語判定を持つ：日本語の文は英語へ、それ以外の文は日本語へ自動で訳す。アプリ側で言語判定ロジックを作り込まないこと。原文言語・訳出先言語の表示は「自動判定」「自動判定（日or英）」とする。
- 画面：原文テキストエリア、訳文表示エリア、「ペーストと同時に翻訳」チェックボックス（既定オン：ペースト時および入力が止まって少し待つと自動で翻訳が走る）、「クリア」ボタン、「翻訳する」ボタン、訳文のコピーボタン。翻訳中は処理中であることが分かる表示にする。
- ローカルサーバーに接続できない場合は、外部サービスで代替せず、「ローカル翻訳サーバーが起動していません」と明示するエラーを表示すること（偽の訳文やダミー訳を出さない）。
- 翻訳履歴などの保存は不要。入力した原文はこのVMの外へ送らないことが分かる一文を画面に置く。
